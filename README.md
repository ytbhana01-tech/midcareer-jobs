# 다시, 일하다 — 중장년 채용정보

전국 공공기관 채용공고를 검색하는 정적 웹사이트입니다. 공무직·무기계약직을 우선 표시하고 지역, 고용형태, 경력, 학력을 필터링합니다. 기관 원문과 지원 자격·전형 절차를 확인할 수 있습니다. 모바일 320px부터 지원하며 광고 배치 공간을 마련했습니다. 실제 광고·추적 스크립트는 포함하지 않습니다.

## 로컬 실행

Python 3.12 표준 라이브러리만으로 수집과 빌드가 가능합니다.

```sh
python -m unittest discover -v
python build.py
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

기존 체크아웃에서 작업하세요. 별도 Git worktree는 필요하지 않습니다. `dist`는 웹페이지, 스타일, JavaScript, 공개 피드, `.nojekyll`만 포함합니다. 서버 코드, 환경 설정, 테스트는 배포하지 않습니다.

## ALIO 데이터 수집

서버 환경에 `ALIO_API_KEY`를 안전하게 주입하고 실행합니다. 기본 주소는 `https://opendata.alio.go.kr`이며 `ALIO_BASE_URL`로 지정할 경우에도 이 주소만 허용합니다. 키를 명령행 인수, 브라우저, 파일이나 로그에 기록하지 마세요.

```sh
python collect.py
```

공식 Swagger 명세: <https://opendata.alio.go.kr/new/v2/api-docs?group=recruit>

- `POST /new/v1/recruit/list.do`: `serviceKey`, `pageNo`, `numOfRows`, `ongoingYn=Y`
- `POST /new/v1/recruit/detail.do`: `serviceKey`, `sn`
- 목록의 모든 페이지를 수집하고 게시 대상 공고마다 상세 API의 일련번호를 대조합니다.
- 실패하거나 응답 구조가 변경되면 기존 `jobs.json`과 수집 시각을 보존하고 실패 종료합니다. 리디렉션을 통한 키 전달을 거부합니다.
- API 원본 응답 전체를 게시하지 않고 공개 필드만 내보냅니다. 키가 응답에 반사되면 게시를 중단합니다.

### 현재 실제 검증 상태 (2026-11-01)

인증 API는 공식 명세대로 호출했으나 목록과 상세가 `SERVICETIMEOUT_ERROR`(코드 5)를 반환했고 일부 목록 요청은 연결이 끊겼습니다. 인증 API 성공 또는 인증키 유효성을 확인했다고 주장하지 않습니다.

미리보기에는 **ALIO 공식 공개 조회 화면의 실제 목록·상세 데이터**를 사용했습니다. 아래는 인증 API와 구분되는 명시적인 대체 모드이며, 인증 API 호출 성공으로 간주하지 않습니다.

```sh
python collect.py --public-preview
```

공개 조회 `/new/odaApiMng/recrutInquiryAjaxList.do`에서 진행 중 482건을 조회하고, 필터링한 모든 게시 대상의 `/new/odaApiMng/recrutInquiryAjaxDetail.do` 상세를 확인하여 421건을 게시했습니다. 날짜·원문 URL·필수 필드 검증을 통과한 공고만 포함됩니다. HTTP 원문, 누락되거나 유효하지 않은 원문, 종료·미시작 공고는 게시하지 않습니다. 원문 URL은 임의의 기관 홈페이지나 포털 링크로 바꾸지 않습니다.

이 모드의 피드는 `source: alio-public-preview`, `authenticated_api_verified: false`로 표시하며 웹페이지에서도 인증 API 연결 대기 상태를 알립니다. 원본 데이터가 없을 때 가상 공고를 만들지 않습니다.

디자인만 배포할 때는 Actions의 `workflow_dispatch`에서 `reuse_published_feed`를 선택할 수 있습니다. main에서 현재 공개 피드를 검증해 그대로 사용하며 수집 시각을 바꾸거나 수집 캐시를 덮어쓰지 않습니다. 기본값은 꺼짐으로, 일반 main 갱신과 정기 일정은 기존 수집을 수행합니다.

## 분류와 마감 정책

- 공무직: 원본 공고 제목 또는 고용형태에 `공무직`이 명시된 경우입니다. 공고 내 모든 직종이 공무직이라는 뜻은 아닙니다.
- 무기계약직: 원본 고용형태에 명시된 경우만 태그를 부여합니다.
- 학력무관: 원본 학력 목록에 `학력무관`이 명시된 경우만 포함합니다.
- 경력무관: 원본 경력 구분이 정확히 `경력무관`인 경우만 포함합니다. `신입+경력`은 별도 조건이며 무관으로 추정하지 않습니다.
- 알 수 없는 조건은 `미확인`으로 남깁니다. 연령·정년·직종별 요건에 따라 지원이 제한될 수 있습니다. 중장년 전용 공고 또는 지원 가능 여부를 보장하지 않습니다.
- ALIO의 광주·전남 통합 지역을 유지합니다. 전국 지역을 조회할 수 있지만 ALIO에 없는 기관의 공고까지 포괄한다고 보장하지 않습니다.
- 수집 시와 브라우저에서 한국 날짜 기준으로 종료일이 지난 공고, 시작일 전 공고를 제외합니다. 브라우저는 1분마다 재검사합니다. 당일 마감 시각과 조기 종료는 기관 원문 확인이 필요합니다.
- 수집 후 48시간이 지나면 오래된 데이터임을 알립니다.

## 브라우저 검증

```sh
python -m pip install -r requirements-dev.txt
python -m playwright install --with-deps chromium
python smoke_ui.py
```

시스템 `chromium` 또는 Playwright Chromium을 사용합니다. `CHROMIUM_EXECUTABLE`로 경로를 지정할 수 있습니다. 실제 피드와 고정된 테스트 데이터를 사용해 검색·필터·상세 모달·원문 링크·초기화·더 보기·정렬, 320/390/768/1440px 화면, XSS, 불명확한 조건, 한국 자정의 마감 전환, 피드 장애 처리를 검사합니다. 고정 시각으로 기존 피드를 검증하므로 과거 공고가 실제 사용자 화면에서 다시 노출되지는 않습니다.

## GitHub Pages 배포

1. 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
2. **Settings → Secrets and variables → Actions → New repository secret**에서 `ALIO_API_KEY`를 등록합니다. 클라우드 환경의 키는 GitHub Actions로 자동 복사되지 않습니다. 공개 조회 미리보기는 키가 없어도 동작합니다.
3. **Actions → Collect, test and deploy job listings → Run workflow → main → Run workflow**를 실행합니다.
4. 성공한 실행의 `deploy` 작업과 `github-pages` 환경에 실제 접속 주소가 표시됩니다. 예상 주소는 `https://ytbhana01-tech.github.io/midcareer-jobs/`이지만 배포 성공 전에는 활성 주소로 간주하지 마세요. 비공개 저장소는 계정 플랜의 Pages 지원 여부도 확인해야 합니다.

`main` 변경 및 매일 10:17·16:17 KST에 갱신·검증·배포합니다. 인증 API가 실패하면 명시적인 공개 조회 미리보기로 시도하고, 두 경로 모두 실패하면 기존 피드와 원래 시각을 유지합니다. 공개 웹 산출물만 Pages로 업로드합니다. 실행 토큰은 `contents: read` 및 배포 작업의 `pages: write`, `id-token: write`로 제한합니다. 수집기는 읽기 전용이며 Git 푸시를 수행하지 않습니다.

## Issue #1: ALIO + 나라일터 통합 수집

`python collect_all.py`가 출처별 목록·상세를 수집하고 하나의 검색 피드를 만듭니다. 기존 `collect.py`와 ALIO 인증/공개 조회 대체 경로는 유지합니다. ALIO는 기존 수집기의 목록·상세 검증 결과를 사용하고 기관 사이트의 별도 원문 재검증 여부를 구분해 표시합니다. 출처별 스냅샷을 `.collector-cache/source-feeds.json`에 보관하며 수집 실패 시 해당 출처의 이전 데이터와 시각을 보존합니다. 캐시가 없으면 체크인된 기존 ALIO 피드를 복구 기준으로 사용합니다. 캐시는 퇴거될 수 있습니다.

| 출처 | 수집 경로 | 상태 |
| --- | --- | --- |
| ALIO | 기존 목록·상세, 인증 실패 시 공개 조회 대체 경로 | 유지 |
| 나라일터 | 공식 공공데이터포털 XML 목록·상세 API + 나라일터 HTTPS 원문 | 실제 인증 응답을 검증한 전용 수집기 |
| 부산광역시 | 공식 RSS 존재 확인 | 비활성: 접수기간·robots·항목별 이용조건 미충족 |

나라일터는 [인사혁신처 데이터셋 15156780](https://www.data.go.kr/data/15156780/openapi.do)의 `getList`와 `getItem`을 사용합니다. GitHub Actions secret `NARA_API_KEY`를 수집 단계에만 주입합니다. 로컬에서 실행하려면 같은 이름으로 환경에 안전하게 설정해야 합니다. 키를 채팅·코드·웹페이지·수집 산출물에 넣지 않습니다. ALIO 키를 나라일터로 전송하지 않습니다.

- 한국 날짜 기준 **최근 90일 등록 공고, 전체 공고유형·기관구분**을 모든 페이지에서 읽습니다. 전체 과거 공고를 포괄한다고 주장하지 않습니다. 이 범위를 출처 상태에도 표시합니다.
- 목록의 `idx`, `title`, `insttname`, `enddate`를 상세와 대조합니다. 불일치 공고는 제외하고 건수를 표시하며, 불일치로 모든 후보를 검증하지 못하면 이전 스냅샷을 보존합니다. 페이지 번호·전체 건수·ID 중복·성공 코드 `00`을 확인한 후에만 스냅샷을 갱신합니다. XML entity/DTD는 거부합니다.
- 상세의 실제 지역명 `areaname`을 사용하고 `contents`는 실행되지 않는 일반 텍스트로 표시·검색합니다. 목록과 상세의 유형 코드 배치가 달라 이를 고용형태나 지원 자격으로 추정하지 않습니다.
- `regdate`는 등록일로만 사용합니다. 미문서화된 `begindate`는 실제 본문의 접수기간과 일치하지 않는 사례가 있어 접수 시작일로 사용하지 않습니다. 화면에 시작일 원문 확인을 표시하며 마감 당일 시각도 원문 확인이 필요합니다.
- 공식 나라일터 페이지의 링크 동작을 확인한 `https://www.gojobs.go.kr/apmView.do?empmnsn=<idx>`를 공고 원문으로 제공합니다. robots와 HTTPS 응답 및 제목 일치를 검증합니다. 기관 링크 `link01`은 안전한 HTTPS 주소로 해석 가능한 경우에만 보조 중복 근거로 보관하고 자동으로 접속하지 않습니다.
- API gateway의 `/robots.txt`는 robots 문서 대신 `NO_OPENAPI_SERVICE_ERROR`(HTTP 400)를 반환합니다. 문서화·활용 승인된 정확한 API 경로는 공식 API 계약으로 접근하며, 공개 원문 페이지의 robots 검사는 유지합니다. 기관 홈페이지 HTML을 채용 데이터 수집으로 대체하지 않습니다.

실제 응답 fixture의 출처는 [fixtures 설명](tests/fixtures/README.md)을 확인하세요. 최초 네트워크 검증 기록은 [2026-11-01 보고서](docs/source-validation-2026-11-01.md)에 별도로 보존했습니다. 최종 연결·배포 결과는 [나라일터 연결 검증](docs/nara-live-validation.md)에 기록합니다.

`python collect_all.py --cached-only`는 네트워크 없이 이전 피드의 마이그레이션과 출처 실패 보존을 검증합니다. PR CI는 키 없이 단위·브라우저 테스트를 수행합니다. 병합 전에는 PR 브랜치의 `workflow_dispatch`에서 Actions 키로 실제 수집과 검색·상세 표시를 검사합니다. 운영 배포는 `main`에서만 수행하며, 나라일터의 검증된 현재/캐시 스냅샷이 없으면 배포를 중단합니다.

### 날짜·원문·분류·중복 정책

- 시간대 없는 명시적 접수 시각은 KST로 해석합니다. 날짜만 있는 마감일은 날짜로 표시하고 시각을 만들어 넣지 않습니다. 명시적 마감 시각이 있으면 브라우저에서도 그 시각 이후 제외합니다.
- RSS 게시일을 접수 시작일이나 마감일로 사용하지 않습니다. 마감일 누락·오류, 미시작, 종료 공고는 게시하지 않습니다.
- 원문은 공식 계약의 허용 호스트에서만 요청합니다. robots를 먼저 확인하고 crawl-delay 및 호스트별 최소 1초 간격(부산 기본 2초)을 지킵니다. TLS 검증을 유지하고 리디렉션·DTD/XML entity를 거부합니다. robots 불허 및 원문 404/410은 제외하고, 알 수 없는 전송 오류는 출처 갱신 실패로 처리해 이전 스냅샷을 보존합니다. 기존 ALIO 피드의 원문 접근을 새로 확인하지 못한 캐시는 `원문 재검증 대기`로 표시합니다.
- `공무직`, `무기계약직`, `기간제`는 원본 고용형태/제목의 명시적 텍스트만으로 분류합니다. 고용형태가 명시됐으나 세 범주에 해당하지 않으면 `기타`, 정보 자체가 없으면 미확인입니다. 40~60대 지원 가능 여부나 경력무관을 추론하지 않습니다.
- ID는 `source:notice_id`로 구분합니다. 동일한 숫자 ID가 다른 출처 공고를 제거하지 않습니다. 원문 URL의 추적 파라미터·fragment·기본 포트를 정규화하되, 여러 공고가 하나의 게시판 주소를 공유할 수 있어 **기관·제목·접수기간이 일치할 때만** URL 중복으로 묶습니다. 공식 기관코드+공고번호가 일치하면 다른 URL도 묶습니다. 모든 출처 attribution을 보존하며 조건을 합쳐 지원 자격을 넓히지 않습니다.
- 출처별 최신/이전 데이터/연결 대기 상태를 화면에 표시합니다. 갱신 실패 때 전체 데이터가 최신인 것처럼 수집 시각을 바꾸지 않습니다.

PR CI는 secret을 전달하거나 외부 수집을 실행하지 않고 단위 테스트, 기존 피드 마이그레이션, 다중 출처 브라우저 검증을 수행합니다. `main`의 자동 일정과 Pages 배포는 유지하며, PR 브랜치를 운영 Pages에 배포하지 않습니다. `dist`에는 수집 설정, 캐시, fixture, 키가 포함되지 않습니다. 부산시는 활성화되지 않았으며 나라일터 검증과 구분합니다.
