# 중장년 채용정보

중장년 구직자를 위한 공공기관 채용공고 검색 웹사이트 프로젝트입니다.

## 목표
- 공무직·무기계약직 등 공공기관 채용공고 검색
- 지역·고용형태·경력·학력 조건별 필터
- 공식 채용공고 원문 연결 및 마감일 표시
- 광고 영역을 고려한 반응형 웹사이트

## 진행 상태
- GitHub 저장소 생성 및 연결 완료
- 채용정보 오픈API 활용 승인 완료(사용자 확인)
- 사이트 시제품 v0.2 제작 완료(아직 저장소에 업로드되지 않음)
- **공식 API 실제 연결·자동 갱신·배포는 미완료**

## 보안
API 인증키는 코드에 직접 기록하지 않고 GitHub Actions Secrets의 `ALIO_API_KEY`에 등록합니다.

## 다음 단계
1. 시제품 파일을 저장소에 업로드
2. 공식 API 응답 형식 확인 및 연동
3. 자동 갱신 워크플로 구성
4. 배포 및 실제 공고 검증

공식 API 이용약관 및 광고 기반 서비스에서의 재사용 조건은 별도로 확인합니다.
