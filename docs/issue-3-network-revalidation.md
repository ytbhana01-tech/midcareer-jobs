2026-11-01 KST. 신규 수집처의 게시 검증은 완료되지 않았다. PR은 초안으로 유지하며 병합·배포하지 않는다. 기존 ALIO·나라일터 설정, 수집기와 운영 일정은 변경하지 않았다.

## 환경과 실제 응답

`cloud_environment.environment_status`는 현재 관측, `unrestricted/enforced`를 보고했고 로컬 정책 파일도 동일했다. 이전 인계의 도메인 미적용 문제는 이 새 환경에서는 재현되지 않았다. 명령 실행 샌드박스의 네트워크 권한이 별도로 필요하여 지원되는 추가 네트워크 권한으로 실행했다. 기존 프록시와 TLS 검증을 유지했다. 접속 실패를 설정 미게시로 오인하여 사용자에게 재승인을 요구할 필요가 없다.

정확한 요청 주소·상태·응답 해시는 [검증 메타데이터](issue-3-network-revalidation.json)에 있다. 외부 HTML과 첨부파일 본문은 저장소에 재배포하지 않았다.

부산교육청 정책은 “공공누리가 부착되지 않은 자료들을 이용하고자 할 경우에는 해당 자료 담당자와 사전에 협의”하도록 명시한다. 공통 메뉴의 공공누리 링크나 `kogl.css` 로드는 개별 공고의 이용허락 표시가 아니다. 첨부파일은 다운로드하지 않았으며, 첨부파일에 허락 표시가 없다고 단정하지 않는다. 담당자 문의·재배포 허락 신청은 발송하지 않았다.

첫 상세는 배움터지킴이 **자원봉사자** 모집이며 접수 시작일이 11월 2일이다. 목록에는 최종합격자 공고도 섞여 있다. 목록 행 수를 접수 중인 유급 채용공고 수로 보고하거나 등록일을 접수 시작일로 대체해서는 안 된다. 이번 제한된 상세 조사로 부산교육청 전체에 허락 가능한 공고가 없다고 결론 내리지 않는다.

## 기존 기능 검증과 남은 일

- 단위 테스트 63개 통과.
- 별도로 받은 운영 피드 1,178건으로 브라우저 회귀 통과: 나라일터 상세·출처·attribution, 검색·필터·정렬·페이지, 320/390/768/1440px, XSS, KST 마감과 장애 처리. 페이지 오류 0건. 체크인된 jobs.json은 실행 후 원복했다.
- 새 클라우드에는 ALIO 키만 준비되어 있으며 나라일터 키는 없다. 기존 두 출처의 신규 API 전체 수집을 이번 세션에서 실행했다고 주장하지 않는다. 기존 Actions secret이나 ALIO 키를 읽어 다른 출처에 사용하지 않았다.
- 신규 정규화 후보 피드는 생성하지 않았다. 신규 고유 공고 수는 **미측정**이며 0건이 아니다. 신규 실수집 Actions와 운영 배포는 실행하지 않았다.

다음 단계는 부산교육청의 공식 지원 피드/API 또는 허용된 게시판 계약과 개별 재이용 근거 확보, 클린아이의 접근 가능한 공식 공고 계약 확인이다. 근거가 확인된 출처에 한해 어댑터·실응답 fixture·실수집·고유 수 비교·브랜치 Actions를 검증한다. 이번 200 응답이나 기존 나라일터 회귀 통과를 신규 출처 병합 조건 충족으로 간주하지 않는다.
