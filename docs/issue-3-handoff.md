## 재현 명령

```sh
python -m unittest discover -v
python -m scripts.audit_sources /path/to/baseline.json \
  --candidate /path/to/candidate.json \
  --as-of 2026-11-01T23:00:00+09:00 \
  --output /path/to/comparison.json
python smoke_ui.py
git diff --check
```

`--as-of`는 저장한 실제 수집 시각으로 바꾸거나 생략해 현재 KST를 사용한다. 후보는 정규화된 jobs.json 스키마다. 권리·실수집 검증을 통과하지 않은 입력의 비교 결과를 배포 가능한 공고 수로 보고하지 않는다. 여러 후보 출처의 독립 추가 수를 합산하지 않는다. 후보가 기존 두 중복 그룹을 연결할 때 `additional_unique`와 `net_feed_change`는 다를 수 있다.
